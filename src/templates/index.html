Connect your AI client

Connect to Google Gemini / AI Studio

  • 1 Open aistudio.google.com and sign in.
  • 2 Click the gear icon → Settings → MCP Servers.
  • 3 Click + Add MCP Server. Set transport to SSE.
  • 4 Paste the URL you copied above. Click Save.

Connect to Claude Desktop

  • 1 Open Claude Desktop. Click the menu → Settings → Developer.
  • 2 Click Edit Config.
  • 3
    Add the following JSON configuration:
    "mcpServers": { "whatsapp": { "command": "node", "args": ["...mcp-client...", "sse", ""] } }

Connect to Cursor IDE

  • 1 Open Cursor. Click the gear icon → Cursor Settings → Features.
  • 2 Scroll to MCP and click + Add New MCP Server.
  • 3 Set the type to SSE.
  • 4 Paste the URL you copied above and click Add.
